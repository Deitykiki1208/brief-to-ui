# 组件与交互

来源编号见 [sources.md](sources.md)。Web 语义、CSS 像素和键盘规则不能直接当作所有原生 App 或小程序 API。

## 按钮 [S01]

动作使用动作语义，跳转使用链接语义。标签说明动作；只有图标的控件需要可理解的名称。用主、次、危险等层级帮助选择，不让所有动作争夺相同注意力。

按任务定义默认、悬停、按下、焦点、禁用和加载状态。加载时保留控件的空间与尺寸，反馈操作正在进行，并合理处理重复提交。禁用原因需要能在适当位置被理解。

反馈可以通过颜色、边框、焦点和状态内容表达，不要求每个按钮都缩放、弹跳或使用过渡。动作名称直接表达结果，不给每个按钮添加重复副标题。图标使用统一的开源 UI 图标，视觉与文案规则见 [visual-foundations.md](visual-foundations.md)。

触控目标按当前平台标准和使用环境核对。WCAG 2.2 AA SC 2.5.8 使用至少 24×24 CSS px 或满足规定的间距等例外；44×44 的增强规则是另一标准层级，不是所有控件的统一 AA 要求。更大目标可以是针对触控场景的设计选择。[S11]

## 输入与验证 [S02]

持久标签说明填什么，提示说明如何填，错误说明哪里不对与如何修正。占位文字消失后，用户仍应能辨认字段含义。

验证时机取决于内容：不要在简单输入尚未完成时不断报错；密码等复杂规则可以及时提供帮助。错误后保留有效输入。只读内容需要可阅读、可选择或复制时，不要用禁用状态替代。

数字外观不决定字段类型：电话、编号、验证码与可计算数量有不同需求。按平台选择键盘、格式和校验；不要因目录里的旧示例统一把所有字段改成某个 HTML 类型。

检查：长输入、空值、非法值、服务器错误、重试与提交后的状态；标签和错误是否能被辅助技术正确关联。

## 卡片与表格 [S08, S09]

卡片先有正确的标题、内容与动作结构，再处理整卡点击。整卡链接和内部按钮不能形成嵌套链接或抢夺事件；保留长文本承载与必要的文本选择。链接名称说明去哪里，避免一列表完全相同的“更多”。

表格用于具有行列比较关系的数据。保留标题、行列关联与必要说明；不要为看起来轻盈而删除关键比较字段。小屏可考虑明确的横向滚动或适合任务的另一表达，不能机械折成失去字段关系的卡片。

旧文章的结构思路可以复用；旧浏览器兼容代码、ARIA 绕过方案与滚动实现需要当前官方资料核对。

## 提示与浮层 [S03, S04]

Tooltip 只补充简短、非交互说明，不能藏住完成任务必需的信息；兼顾悬停、键盘焦点、关闭和边界碰撞。需要链接、按钮或复杂内容时考虑其他浮层。触控没有稳定悬停，应提供可发现的替代入口。

模态浮层打开与关闭时管理焦点，键盘操作与背景交互遵循当前平台模式。无障碍原语库可以承担部分机制，调用方仍负责标签和整页流程。不要仅添加 role 就假设行为已完成。

## 动效与反馈 [S13, S16]

用户于 2026-10-25 确认默认减少元素动画和过渡，替换早期强制所有前端具备进出动画、按钮缩放的偏好。先回答动效解释什么：交互已响应、内容从哪里来、对象去哪里或状态如何变化。不能明确帮助理解或操作时省略动画，高频操作避免重复播放装饰。

确有必要的过渡以 ease-out、250ms 为个人调试基线，按距离、频率、输入方式和设备调整，不要求所有反馈延迟 250ms。CSS 可用 ease-out；Motion 的对应配置为 type: "tween"、ease: "easeOut"、duration: 0.25（秒）。显式使用 tween 避免位置变化采用默认弹簧；仅有明确需求时使用弹簧，并按物理参数调试。这些参数是个人偏好，不是 Motion 或无障碍规范的统一要求。

简单变化优先使用 CSS 或平台原生能力。需要手势跟随、共享元素、打断与重定向等复杂衔接时再按资源路由选用 Motion。Morph 仅用于能帮助理解的关联元素，如卡片与其详情；不统一给整页、所有组件和路由添加进出动画。采用过渡的组件检查进入、退出、反向与快速重复操作，不能跳位、丢失滚动位置或阻碍下一次输入。

支持 prefers-reduced-motion 或目标平台的减少动态效果设置，减少位移、缩放与形变并保留明确状态。弹窗无论是否播放动画，焦点、关闭、背景交互和结果反馈都要正确。静态截图只用于外观确认，重要动效用实际可播放演示或交互原型检查。

## 状态完整性：本 skill 的综合检查

按实际任务覆盖加载、空内容、无结果、成功、失败和可恢复路径，不为不存在的流程添加状态。空页面给出必要状态与可行动入口，失败信息给出可行动的修正，成功反馈说明结果；不将状态完整性理解为每种状态都添加标题、副标题、说明段落和动画。

查看键盘焦点、触控可达性、长文本、网络等待与页面内容变化。静态截图不足以验证这些行为。
